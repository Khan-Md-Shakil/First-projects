# 💰 Expense Tracker - Python Project

A simple and beginner-friendly **command-line Expense Tracker application** built with Python.  
This project helps users record daily expenses, view expense history, and calculate total spending.

This is my **first Python project uploaded to GitHub** as I begin my journey in programming and software development. 🚀

---

## 📌 Features

✅ Add new expenses  
✅ Store expense names and amounts  
✅ View all recorded expenses  
✅ Calculate total spending  
✅ Simple menu-driven interface  
✅ Beginner-friendly Python code

---

## 🛠️ Technologies Used

- 🐍 Python 3
- 💻 Command Line Interface (CLI)
